## 3. Validate plan

- **Provider stays neutral.** The setting is `PROVIDER_API_KEY` because the provider is confirmed at T1.6.

## 5. Validate implementation

**Design change.** `extra="forbid"` caught typos in `.env` but crashed on any unrelated entry, and `.env` files are often shared with other tools. Changed to `extra="ignore"`, because every misspelling here fails safe:

| Misspelled | Result |
|---|---|
| Mode | Stays `offline_demo` |
| Trace flag | Stays off |
| API key | `live` refuses to start |

The trade-off is that a typo isn't reported, so `live` could silently run offline. Tests assert the fail-safe behaviour.

**Reversed by [R1](../reviews/R1.md).** The claim above was wrong. A misspelled opt-out, such as `INCIDENTPILOT_MOD=offline_demo` over a `live` value in `.env`, was ignored, leaving paid calls on. Unknown `INCIDENTPILOT_` names are now rejected, and unrelated entries are still ignored.

**A weak test found by mutation.** Disabling `hide_input_in_errors` broke no test, so the canary test wasn't exercising it. On that path Pydantic prints the object with the key already masked. The realistic leak is a key pasted into the wrong setting, such as `INCIDENTPILOT_MODE=sk-...`, so the test now covers that, and the code comment was corrected.

**Mutation results.** One protection removed at a time, in a throwaway copy:

| Protection removed | Result |
|---|---|
| `live` requires a key | Caught |
| Trace export rejected outside `live` | Caught |
| Trace export defaults off | Caught |
| Default mode is `offline_demo` | Caught |
| Egress only in `live` | Caught |
| Blank key counts as missing | Caught |
| Errors hide raw input | Caught, after the fix above |
| Key stored as `SecretStr` | Caught |
| Original exception dropped | Caught |
| Settings immutable | Caught |
| Unrelated `.env` entries tolerated | Caught |
| `.env.example` matches the settings | Caught |

**Later correction (T1.2):** the mutation runs above could have reused stale bytecode, which can report a false catch. They were rerun in T1.2 with bytecode reuse off, each caught by the expected test, and the results held.
