## 3. Validate plan

- **No runtime dependencies yet.** Each arrives with the first code that needs it.
- **`uv`-managed Python** (`python-preference = "only-managed"`), so CI and contributors get the same interpreter instead of whatever the host has.
- **Spec stays frozen** (delivery plan decision). This is now enforced by a test.
- **"No network" must be tested with the network blocked,** not assumed from having no API key.

## 4. Implement

Commit: `git log --grep='T0.2'`.

Pinned by `uv.lock`: Python 3.12.16, ruff 0.17.4, mypy 2.4.1, pytest 9.2.0.

## 5. Validate implementation

**Defect found and fixed.** The first `make check` failed because this ruff version also formats Python code blocks inside Markdown. `make format` would have rewritten the frozen spec and broken its hash. `docs` is now excluded in ruff's config, so a hand-run `ruff format .` is protected too.

**Each gate was shown to fail.** One fault at a time was injected into a throwaway copy:

| Fault | Gate | Result |
|---|---|---|
| Unused import | `make lint` | Failed as expected |
| Bad formatting | `make lint` | Failed as expected |
| Untyped function | `make types` | Failed as expected |
| Failing test | `make test` | Failed as expected |
| Spec edited | `make test` | Failed as expected |
| Dependency added without relocking | `make lock-check` | Failed as expected |

## 6. Test

The copy held only tracked and new files, so nothing was inherited from the working `.venv`.

| Check | Result |
|---|---|
| `uv sync --frozen` from the lockfile in a clean copy | Pass |
| Network block is real: `curl` to PyPI under `sandbox-exec` | Pass: `000` blocked, `200` control |
| `make check` with network blocked and a stripped environment | Pass: exit 0, 3 tests |
| Same, after forcing a package rebuild | Pass: exit 0 |
| `ruff format .` leaves the spec hash unchanged | Pass: `c140a3c4…` |

**Limits:**
- "No network" applies after `make sync`. First setup needs network to fetch Python and packages.
- The network-blocked runs used this machine's warm `uv` cache. A cold-cache run is covered when T0.4 runs on CI.
- The suite is 3 tests, because there's no domain code yet.
