# R1 — Staff review of T0.1 to T1.2

**Scope:** all code, tests, config and CI up to T1.2, plus a check of the code against the spec and errata.

**Methods:** a full read-through, the code-review skill, automated mutation testing (`mutmut`), property-based fuzzing (`hypothesis`), an install of the built wheel, and independent leak probes. Fuzzing and `mutmut` ran in throwaway copies and aren't project dependencies.

## Result

Coverage was already 100% for lines and branches, and 123 hand-picked mutations had passed. This review still found 2 security issues and 14 other defects or gaps. **Coverage shows code ran. It doesn't show that a test would notice the code being wrong.**

All of the findings below are fixed. Each fix has a test that was seen failing first, except the CI, Makefile and config changes.

## Not verified

- **CI changes haven't run on GitHub.** That includes the network test, which can only run there, and the `cancel-in-progress` change.
- **Number storage** was simulated with decimal text, not run against real PostgreSQL. T3.11 must confirm it with JSONB.
- `mutmut` skips module-level tables and enum values. The edge mutations and pinned-value tests cover those.
- **The wheel** wasn't rebuilt after the fixes.
